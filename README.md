# Backend Learning

Personal backend engineering learning repository.

## Stack

Node.js → NestJS → PostgreSQL → Prisma → Docker

## Learning workflow

1. Prepare lesson
2. Study official documentation
3. Complete assignment independently
4. Submit solution for code review
5. Fix review findings
6. Complete knowledge assessment
7. Mark lesson as mastered

## AI usage

AI agents may prepare materials, explain concepts and review code.

Practical assignments are completed independently unless explicitly
stated otherwise.

See AGENTS.md for agent rules.
