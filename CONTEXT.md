# Учебные материалы

Термины для организации теории в этом репозитории.

## Language

**Теоретический документ**:
Самостоятельный русскоязычный материал для первого изучения содержания одного указанного первоисточника. Последовательно охватывает разделы первоисточника и содержит ссылку на него.
_Avoid_: Краткий конспект, перевод статьи

**Первоисточник**:
Статья или страница официальной документации, которой соответствует один теоретический документ.
_Avoid_: Урок

**Урок**:
Материал учебной программы с целями, документацией и самостоятельным практическим заданием; может ссылаться на несколько теоретических документов.
_Avoid_: Теоретический документ
