# About Node.js

Первоисточник: [About Node.js](https://nodejs.org/en/about). Сверено 14.10.2026; для объяснений используется Node.js v24.21.0 LTS.

## Что такое Node.js

Node.js — кроссплатформенный JavaScript runtime с открытым исходным кодом. Он исполняет JavaScript вне браузера, в частности для серверов, инструментов командной строки и автоматизации. Runtime включает V8 для исполнения JavaScript, стандартные API Node.js и libuv для координации I/O. Node.js не является языком программирования или web framework.

## Асинхронная модель и Event Loop

Node.js ориентирован на событийную обработку: программа регистрирует действие, продолжает работу и получает callback или результат Promise позже. Ожидание сетевого ответа обычно не требует отдельного JavaScript thread для каждого соединения. Event Loop возвращается к готовым событиям, когда текущий JavaScript callback завершился. Поэтому множество ожидающих I/O соединений можно обслуживать небольшим числом threads.

Это не означает, что всё приложение «однопоточное». JavaScript callbacks в одном isolate обычно выполняются последовательно, а libuv Worker Pool и некоторые другие компоненты используют дополнительные threads. Если один callback долго считает на CPU, остальные готовые callbacks ждут; асинхронный API сам по себе не делает синхронный расчёт фоновым.

## Зачем эта модель подходит для сервера

Операции сети преимущественно проводят время в ожидании. Когда ожидание не удерживает JavaScript thread, сервер может уделять время другим запросам. Цена такого устройства — необходимость держать каждый callback коротким и понимать, какая работа действительно передана ОС или Worker Pool. Для CPU-intensive задач нужны иные стратегии: разделение работы на короткие шаги либо отдельный исполнитель.

Официальная страница показывает простой HTTP server: callback вызывается для каждого соединения, а после завершения top-level скрипта Node.js сам входит в Event Loop. Отдельный вызов «запустить цикл» в приложении не нужен; процесс завершится, когда работа, удерживающая цикл, закончится. HTTP и streaming входят в основные области применения Node.js. Для использования нескольких CPU cores возможны дочерние процессы и `cluster`; они не меняют правило выполнения callbacks внутри одного isolate.
